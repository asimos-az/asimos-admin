# Asimos Admin Panel

React (Vite) admin UI for the Asimos mobile app.

## Config

Create `.env` from `.env.example`:

```
VITE_API_BASE_URL=https://asimos-backend.onrender.com
```

## Run

```bash
npm install
npm run dev
```

## Login

Default static super admin:
- Email: `admin@asimos.local`
- Password: `admin1234`

> Change these by setting backend env vars: `ADMIN_EMAIL`, `ADMIN_PASSWORD`, `ADMIN_JWT_SECRET`.

## Career content

Open **Karyera məsləhətləri** in the sidebar (`/career-articles`) to create,
preview, edit, publish, unpublish, or delete articles. The backend career
migration must be applied first. Drafts are visible only in the admin panel.
Featured articles are shown first; the first three published articles appear on
the website homepage. Cover images accept HTTPS URLs, with four built-in cover
styles available when no image is provided.

Set optional `VITE_WEB_URL` to change the **Saytda aç** link target (default:
`https://asimos.az`). The editor supports paragraphs, `##` headings, `-` lists,
and `>` quotes. Reading time is generated by the backend.
